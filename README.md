# Bank Management System

A simple command-line Bank Management System built with Python and PostgreSQL.

## Features
- Create Account
- Deposit Money
- Withdraw Money (with balance validation)
- Check Balance
- View Transaction History

## Technologies Used
- Python
- PostgreSQL
- psycopg2 (Python-PostgreSQL connector)

## How to Run
1. Make sure PostgreSQL is installed and running
2. Create a database named `bank_practice`
3. Install psycopg2: `pip install psycopg2`
4. Update the database credentials in `bank_app.py`
5. Run the program: `python bank_app.py`
